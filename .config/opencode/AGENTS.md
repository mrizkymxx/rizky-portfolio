# Global Instructions

## Skills — pakai secara proaktif (tanpa diminta)

Gunakan skill di bawah ini OTOMATIS begitu konteks tugas cocok, tanpa menunggu
perintah eksplisit dari user:

- **brainstorming** — sebelum menulis kode apa pun: untuk tugas kreatif/desain baru (fitur, komponen, ganti fungsi), gali kebutuhan & desain lebih dulu.
- **impeccable** — semua pekerjaan yang menyentuh tampilan frontend (website, landing page, dashboard, UI React): anti-desain generik, anti-borok.
- **ponytail** — aturan hemat kode terpasang secara global tiap turn: tulis sesedikit mungkin, pakai stdlib/native, YAGNI.

Prioritas: kalau dua skill bentrok, ikuti yang paling spesifik ke tugas.

## Prinsip global

- Jawab ringkas. Jangan menambah penjelasan/perkenalan/penutup yang tidak diminta.
- Tulis kode seminimal mungkin yang benar (ponytail).
- Gunakan skill = muat konten SKILL.md sebelum bekerja pada domain itu.

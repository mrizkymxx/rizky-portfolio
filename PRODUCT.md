# PRODUCT — Portfolio Lamaran IT Support (Rizky)

## Positioner
- **Apa:** Satu halaman web portofolio profesional untuk posisi IT Support.
- **Siapa:** Rizky (nama disesuaikan saat profil GitHub/LinkedIn terbaca).
- **Untuk apa:** Dilampirkan ke lamaran kerja sebagai bukti kemampuan; dibaca HRD < 60 detik.
- **Sumber konten:** GitHub, LinkedIn, dan proyek/riwayat yang dinyatakan pemilik.

## Audiens
1. **HRD** — cek cepat: profil sesuai posisi tidak, rangkuman jelas, kontak tersedia.
2. **Interviewer/IT lead** — cek kedalaman: keterampilan spesifik, proyek nyata dengan dampak.

## Tujuan
- Key info (nama, peran, skill inti, kontak) terlihat di layar pertama.
- Keahlian dikelompokkan fungsi (OS, Jaringan, Helpdesk/Ticketing, Keamanan, Cloud & Tools).
- Pengalaman/Proyek ditulis **judul → dikerjakan → hasil**; sertifikat ditampilkan (penting untuk junior).
- Nada: **presisi · jelas · tepercaya** — tidak playful, tidak berlebihan.

## Syarat Isi (wajib)
- Pernyataan mimpi: "masuk ke departemen IT adalah mimpi saya" (harus ada, persis atau padanan jelas).
- Bahasa `id`, formal, singkat.
